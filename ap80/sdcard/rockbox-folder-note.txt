This folder is here so that the boot menu of the Hidizs AP80 Pro Max can remember
which player you started last (it writes rb_bl_mode.txt into it).

It is also where Rockbox lives, if you install it: https://www.rockbox.org/wiki/HidizsPort
You can leave this file here or delete it. Keep the folder.

Sonix for the AP80 Pro Max: https://github.com/Fos4ity/sonix-ap80
